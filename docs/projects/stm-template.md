# STM Template

STM Template is a reusable embedded software project structure.

## Features

- CMake based build system
- STM32 support
- Host unit testing
- Doxygen documentation
- CTest
- Unity
- Azure Pipelines

## Architecture

The project is divided into several layers:

- Application
- Middleware
- BSP

## Getting started

Clone the repository and run the setup script.
