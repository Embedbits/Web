# Testing

STM Template supports both embedded-target builds and host-based unit testing.

## Unit tests

Unit tests are implemented using [Unity](../../artifacts/tools/unity.md), with mocks generated by
[CMock](../../artifacts/tools/cmock.md). Tests can be executed on the host without the target MCU.

## CTest

CTest integrates the unit tests into the CMake build system. A typical workflow:

```bash
cmake --build build
ctest --test-dir build
```

## Embedded testing

Embedded-target tests can be combined with hardware-specific integration tests, and
[Renode](../../artifacts/tools/renode.md) can be used to simulate the target.

This lets the same project distinguish between:

- Host unit tests
- Target integration tests
- Hardware compatibility tests
