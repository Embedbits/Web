# STM Template

STM Template is the foundation for Embedbits embedded software projects.

It provides a reusable project structure for embedded C/C++ development with CMake, BSP components, testing and development tooling.

## Goals

- Reusable project structure
- Clear separation between application, middleware and BSP
- Cross-platform development
- Host-based unit testing
- Embedded target builds
- Automated documentation and CI/CD

## Supported concepts

The project structure is designed around:

- Application
- Middleware
- BSP
- MCAL
- RAL
- Build infrastructure
- Unit testing
