# Getting Started

## Prerequisites

The development environment requires:

- Git
- CMake
- Ninja
- A supported compiler toolchain
- Doxygen for documentation generation

## Project setup

Clone the STM Template into the project root.

Then initialize the project using the provided helper tools.

```text
CMake/HelperTools/Setup.bat
```

### On Linux:

CMake/HelperTools/Setup.sh

Build

Create a build directory and configure the project with CMake.

The exact configuration depends on the selected target and toolchain.

## Documentation

Doxygen can be used to generate API documentation from the source code.
