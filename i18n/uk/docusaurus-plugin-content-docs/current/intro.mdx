# Embedbits

Embedbits — це збірка проєктів embedded-софту, інструментів, документації та статей,
присвячених підтримуваній розробці під STM32.

Платформа поділена на незалежні репозиторії, які об'єднуються в проєкт як Git submodules.

## Будівельні блоки

| Область | Що вона надає |
|---|---|
| [Платформа](./platform/embi-platform/index.md) | Скрипти налаштування `EmBi_Platform`, допоміжні засоби CMake та шаблони проєктів. |
| [Стиль кодування](./platform/embi-platform/coding-style.md) | Правила іменування, форматування та документування, що застосовуються в усьому коді Embedbits. |
| [Дизайн та архітектура](/blog/design-architecture) | Як розділити embedded-софт на модулі та рівні абстракції (RAL, MCAL, HAL, BSP). |
| [BSP](./bsp/index.md) | Board Support Package: linker, startup, RAL і MCAL для кожної родини STM32. |
| [Артефакти](./artifacts/index.md) | Версіоновані інструменти збірки (GCC, Ninja, Doxygen, Unity, CMock, Renode, ...), які завантажує Artifacts Handler. |

## Рівні

```text
Application
Middlewares
BSP
├── MCAL      peripheral drivers (GPIO, USART, I2C, ...)
├── RAL       unified access to CMSIS and STM32 LL
├── Startup   reset handler, memory initialization
└── Linker    linker script generation
```

## Звідки береться контент

Сторінки в розділах «Платформа», BSP та «Артефакти» генеруються з `README.md` відповідного
репозиторію в [організації Embedbits на GitHub](https://github.com/Embedbits). Вони синхронізуються
автоматично, тож README репозиторію завжди є джерелом істини. Скористайтеся посиланням **Редагувати цю сторінку**
на будь-якій із цих сторінок, щоб перейти до потрібного README.
